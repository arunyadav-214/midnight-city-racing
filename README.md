# Midnight City Racing

A real-time 2-player browser racing game with a nighttime city street circuit.

## Features
- Online room-code multiplayer
- Host and join from different devices
- 3-lap street race
- City blocks, streetlights, checkpoints, and road boundaries
- Keyboard controls: WASD or arrow keys
- Mobile touch controls
- Live synchronized race state
- Winner screen and rematch

## Play
When GitHub Pages is enabled, the game will be available at:

https://arunyadav-214.github.io/midnight-city-racing/

## Multiplayer note
The host player's browser acts as the authoritative race host. The host should keep the game tab open while playing.
